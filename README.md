# Hi, I'm Galantryas

I'm a full-stack developer working with Laravel and Vue. I also build desktop utilities, games, and tools for developers.

## Selected projects

- [Port Sentinel](https://github.com/Galantryas/port-sentinel) — A desktop utility for inspecting listening ports and the processes using them. Built with Tauri, Svelte, and Rust.
- [LAN Drop](https://github.com/Galantryas/lan-drop) — A desktop app for discovering peers and sharing files or clipboard text over a local network.
- [Antigravity OpenRouter](https://github.com/Galantryas/antigravity-openrouter) — An extension that connects OpenRouter models to the Antigravity agent chat.
- [Snake & Ladder](https://github.com/Galantryas/snake-ladder) — A browser-based snakes and ladders game built with vanilla HTML, CSS, and JavaScript.
